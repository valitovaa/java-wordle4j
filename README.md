# Wordle Game 
A console‑based implementation of the popular Wordle game in Java. Challenge yourself to guess a 5‑letter word in 6 attempts!
Features: * 5‑letter Russian word guessing; * hints for each attempt (+ — correct letter and position, ^ — correct letter but wrong position, - — letter not in the word); * in‑game word hint generator based on previous guesses; * game progress logging to a file; * error handling for invalid inputs.
